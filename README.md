# Trading Bot ML

Bot de trading algorithmique avec Machine Learning (Random Forest + LSTM PyTorch).

## Structure
- data/        → données historiques SPY
- models/      → modèles entraînés
- notebooks/   → jupyter notebooks par module
- scripts/     → scripts Python autonomes

## Stack
- Python 3.12 / PyTorch / scikit-learn
- yfinance / pandas-ta / mplfinance
